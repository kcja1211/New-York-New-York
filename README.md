# 부모님 첫 뉴욕여행 체크리스트

GitHub Pages에 바로 배포할 수 있는 정적 HTML 사이트입니다.

## 배포 방법
1. GitHub에서 공개(Public) 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 최상위(root)에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**를 선택합니다.
4. Branch에서 **main**, 폴더에서 **/(root)**를 선택하고 Save를 누릅니다.
5. 배포 후 `https://사용자명.github.io/저장소명/`으로 접속합니다.

## 사용 방법
- 명소를 체크하면 해당 브라우저의 로컬 저장소에 선택 상태가 저장됩니다.
- `이미지로 저장 (PNG)` 버튼을 누르면 체크 결과를 이미지로 다운로드합니다.
- 브라우저 또는 기기를 바꾸면 체크 상태는 자동으로 공유되지 않습니다.

외부 라이브러리나 빌드 도구가 필요 없습니다.
